Crea una sala privada o únete a otra con su nombre y contraseña. Para Camaleón, ambos eligen ese modo: el anfitrión será el buscador y el invitado uno de los cuatro escondedores (tres bots completan el equipo). Ambos deben usar la misma red local.

BLUETOOTH PAN
Prueba experimental para jugar por una red local creada a través de Bluetooth.

Importante: el navegador no puede convertir este HTML en un anfitrión Bluetooth directo. Este modo usa Bluetooth PAN (una conexión de red por Bluetooth), así que la partida utiliza el mismo servidor LAN, pero el tráfico puede viajar por Bluetooth en vez de Wi-Fi.

  1. En tu Android, activa Bluetooth y empareja el teléfono con la laptop.
  2. En Android, abre Ajustes → Conexiones / Redes → Zona Wi-Fi y compartir conexión y activa Anclaje por Bluetooth (el nombre puede variar).
  3. En Windows, ve a Configuración → Bluetooth y dispositivos → Dispositivos. Junto a tu teléfono busca Red de área personal (PAN) → Conectar y elige Punto de acceso si aparece.
  4. Cuando la conexión Bluetooth PAN esté activa, reinicia INICIAR_SERVIDOR.bat. La ventana negra debe mostrar una dirección bajo una interfaz Bluetooth/PAN.
  5. Escribe esa dirección completa en Chrome del teléfono, por ejemplo http://192.168.44.34:8080. Usa la IP real que imprima tu laptop, no este ejemplo.
  6. Abre MULTIJUGADOR LAN desde ambos equipos y crea/únete a la sala normalmente.

Si no aparece una interfaz Bluetooth/PAN o el celular no carga la dirección, tu Windows, el controlador o el firewall puede bloquear esa conexión. No desactives todo el firewall; en una laptop administrada puede requerirse autorización de informática.

Este método no es Bluetooth GATT directo entre navegadores: aprovecha Bluetooth PAN como red IP.
